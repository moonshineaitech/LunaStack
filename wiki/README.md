# LunaStack Wiki — AI Skills Ecosystem Index

A curated map of the wider AI agent/coding-skill ecosystem, indexed **July 2026**,
cross-referenced against LunaStack's own skills. Use it to discover what exists
beyond LunaStack and to compose LunaStack's methodology layer with vendor-specific
skills.

## Pages

- **[catalog.md](catalog.md)** — 140 skill categories across 12 domains. Each names
  real, notable/official skills in the wild and the LunaStack skill that covers the
  same ground (`LS:`). This is the main reference.
- **[registries.md](registries.md)** — the aggregators where skills actually live
  (Chat2AnyLLM, VoltAgent, rohitg00, addyosmani, seb1n, caramaschiHG…) with their
  reported sizes and the first-party vendor skill sets (Anthropic, OpenAI, Microsoft,
  Google, Vercel, Cloudflare, HashiCorp, Trail of Bits…).

## How to use it

- **Discover** — browse [catalog.md](catalog.md) by domain; every category points at
  where its top skills live.
- **Compose** — LunaStack is a *methodology* layer (how to think/work). For framework
  specifics (Next.js, Terraform, Kubernetes, HuggingFace), install the official vendor
  skill *alongside* LunaStack — they stack, they don't conflict.
- **Find gaps** — the `LS: —` markers show where LunaStack has no equivalent yet;
  they're the candidate list for future skills.

## Sourcing & honesty

Compiled from the public registries in [registries.md](registries.md) via web/GitHub
search in July 2026. Rules we held to (the same anti-fabrication discipline the
LunaStack skills enforce):

- **"Top" means verifiable** — officially published by the named vendor, or featured
  across the major awesome-lists. Where a precise popularity *rank* isn't publicly
  verifiable, we name notable entries rather than invent a star count.
- **Counts are as-reported** — registry totals (e.g. "69,201 skills") are what each
  registry reported on the date shown; the ecosystem moves weekly, so treat them as
  orders of magnitude.
- **Named skills are real** — every skill named here appeared in a real registry or
  vendor repo at index time; none were invented to fill a category.

Because the ecosystem changes fast, re-run the index periodically (search the
registries in [registries.md](registries.md)) rather than trusting these snapshots
indefinitely.
